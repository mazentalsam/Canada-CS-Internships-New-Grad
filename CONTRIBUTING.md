# Contributing

Thanks for helping Canadian CS students find their next role! 🇨🇦

## Add a job (under a minute)

1. Go to **[Issues → New issue → ➕ Add a job](../../issues/new?template=add-job.yml)**.
2. Fill in the company, role, location, type and the company's own application link.
3. Submit. Once it's verified, it appears in the list on the next hourly update.

## What qualifies

- **Location:** in Canada, or remote and open to Canadian applicants.
- **Role:** software, data, AI/ML, DevOps/cloud, QA, security, mobile or IT — internships, co-ops, new grad or junior positions.
- **Link:** the company's own posting (careers site or ATS like Greenhouse, Lever, Workday, Ashby), not a reposting site.
- **Open:** the posting must still be accepting applications.

## Something wrong?

Closed posting, wrong location or a broken link? [Open an issue](../../issues/new) — most of the list is updated automatically every hour from company career sites, so closed roles usually disappear on their own within the hour.

## How the list is built

The README is generated every hour by [csjobs.ca](https://csjobs.ca/?utm_source=github&utm_medium=readme) from 40+ company career sites, ATS boards and job feeds. Please don't edit `README.md` directly in a pull request — it's overwritten on the next update. Use the issue form instead.
